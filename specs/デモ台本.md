# 展示会デモ台本

## 1. 基本デモ: Teams

### 事前準備

- .envにMicrosoftの4設定を入れたAPKをインストールする。
- 対象アカウントにChannelMessage.Read.All、ChannelMessage.Send、offline_accessが許可されていることを確認する。
- Rokidの設定で「既定の送信先: Teams」を確認する。
- PC／タブレットで対象Teamsチャネルを開く。
- 誤投稿に備え、展示専用チャネルを使う。

### 進行

1. ロビーに開発用Teamsチャネルの会話が吹き出し表示されていることを見せる。画像は `[画像]` と表示される。
2. ロビー上部の操作メニューから「写真を撮る」を開く。「動画を撮る」は準備中として選べない。「終了」は可視領域の最後にある。
3. 画面右上の送信先がTeamsであることを確認し、縦／横を選んで写真を撮る。
4. コメントを残すか選ぶ。残す場合だけ5秒話し、文字起こし結果を確認する。翻訳はしない。
5. 確認画面で「Teamsに送信しますか？」を確認する。
6. 「はい」を選び、Teamsへ送信する。
7. PCのTeamsで写真とコメントを確認する。
8. PCのTeamsから短い返信を投稿する。
9. Rokidのロビーに返信の吹き出しが増え、Blow通知音・HUD・TTSが動くことを確認する。

初回またはトークン失効時は、Rokidに出たコードを別端末でMicrosoftのデバイスログイン画面へ入力する。offline_accessにより、通常は次回から再入力不要。

コード画面から戻った場合、自動では開き直さない。ロビーの「サインイン」を選ぶと再度コードを表示できる。

## 2. 多言語デモ: PCモニター

### 事前準備

- PCと端末を同一LANへ接続する。
- リポジトリルートでpnpm devを実行する。
- Preactの設定QRをRokidで読み取る。
- 設定で端末言語をja、en、nlのいずれかにする。
- 「既定の送信先: モニタ」を確認する。

### 進行

1. 写真を撮影する。
2. 必要ならコメントを5秒録音して文字起こしする。撮影コメントは翻訳しない。
3. 確認画面で「モニタに送信しますか？」を確認して送る。
4. Preactに写真とコメントが出ることを確認する。
5. ビューア下部から日本語テキスト、またはPCマイクで返信する。
6. Rokidに端末設定言語の字幕が出ることを確認する。
7. Google Cloud TTSが同じ言語で読み上げることを確認する。

## 3. 宛先切替の見せ方

設定画面の「既定の送信先」をタップするとTeamsとモニタが切り替わる。撮影画面では右上の送信先を確認する。

「動画を撮る」は準備中で選べない。TeamsとPCへ同時に送られないこと、確認画面に宛先が明記されることを説明する。

## 4. 復旧

| 症状 | 対応 |
|---|---|
| Teamsコードが出る | 別端末でデバイスログインする。戻る場合はダブルタップ |
| Teams 403 | 管理者同意、チャネル参加、アプリ登録を確認 |
| ロビーに「接続エラー」 | Wi-Fiと外部通信を確認し、画面上部の「再試行」を押す |
| PCに届かない | 同一LAN、PCのIP、ポート8787、共有トークンを確認 |
| 翻訳されない | GEMINI_API_KEYとAPIログを確認 |
| 字幕は出るが音がない | GOOGLE_TTS_API_KEYと端末の外部通信を確認 |
| 古い返信が鳴る | 初回取得は通知しない設計。アプリ再起動後の次の投稿で確認 |

## 5. 注意

- 実チャネルへ送る前に、確認画面の宛先を読み上げる。
- Teams投稿はアプリから削除できない。必要ならTeamsクライアントで削除する。
- 本番チャネル、個人情報、機密設備を展示データに使わない。
