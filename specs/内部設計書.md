# 内部設計書

> 以下はTeams版の設計記録です。現在のSlack版の構成、端末登録、返信振り分けは [Slackでの遠隔支援](Slackでの遠隔支援.md) を参照してください。

## 1. 方針

- UIは外部サービスを直接組み立てず、MediaSink、FeedRepository、Speaker等の境界に依存する。
- AppContainerで実装を一か所に配線する。
- Rokid APK の送受信先は BuildConfig の単一 Teams チャネルに固定する。旧 QR 接続先は無視する。
- Teams 経路は Android の Teams クライアントを使う。PC API は開発用として残すが APK からは接続しない。

## 2. Androidモジュール

| 実装 | 責務 |
|---|---|
| AppContainer | 全依存の生成、利用可能な送信先、Feed取得元の配線 |
| MediaSinks | Teams だけの候補生成、Teams 画像を縮小。未設定なら空 |
| CaptureSettings | 画質・文字サイズ・話速を保存、旧 default_sink を削除して Teams 固定 |
| CaptureViewModel | 写真の縦／横、任意の5秒コメント、確認、設定済み宛先への送信、失敗時の下書き保持 |
| HomeScreen | Teamsチャネル最新20件を10秒間隔で表示、画像を `[画像]` と表す |
| TeamsAuth | Device Code Flow、暗号化トークン保存、リフレッシュ |
| TeamsClient | Graphへの写真＋本文投稿、チャネル取得 |
| GoogleTtsSpeaker | Cloud TTSの合成結果を再生 |

## 3. 送信先の生成

AppContainer は TeamsAuth と TeamsClient を生成する。TeamsClient は BuildConfig.MS_TEAM_ID / MS_CHANNEL_ID のみを参照し、GlassConfig の旧 t/c/u/k を読み取らない。Teams が未設定なら候補は空で、CaptureViewModel は NoMediaSink により未設定を表示する。HTTP モニターへフォールバックしない。

写真のみ Teams へ送れる。動画メニューは準備中として無効化する。設定画面に宛先切替・QR スキャナーは無い。

## 4. Teams認証

- スコープ: offline_access ChannelMessage.Read.All ChannelMessage.Send
- 認証方式: OAuth 2.0 Device Authorization Grant
- 保存先: EncryptedSharedPreferences
- 更新: 有効期限の60秒前からrefresh_tokenで更新
- client secret: 使用しない

AndroidとPC APIにそれぞれTeamsクライアントがある。Android側が基本経路で、PC API側は復旧・検証用である。トークンは共有しない。

## 5. 廃止した APK の PC 経路

UploadClient / LocalReplyClient は APK の main ソースから除去し、既存の撮影フロー回帰試験用に JVM test ソースへ隔離する。DestinationFeedRepository / LocalReplyFeedRepository は削除する。DEV_UPLOAD_URL BuildConfig と ZXing 依存も削除する。

## 6. 旧設定の移行

GlassConfigStore は旧 JSON v1 の言語・認識設定を継続して読み取るが、チームID・チャネルID・HTTP URL・共有トークンは無視し、次回保存時には書き出さない。CaptureSettings の旧 default_sink は起動時に削除し、旧モニター選択でも Teams を使う。

## 7. Teams API

| 操作 | Graph |
|---|---|
| 投稿 | POST /teams/{teamId}/channels/{channelId}/messages |
| 取得 | GET /teams/{teamId}/channels/{channelId}/messages |
| 画像 | hostedContentsと本文内の相対URL |

GraphのHTML本文は表示前にプレーンテキスト化する。投稿本文はHTMLエスケープする。動画、編集、削除は対象外。

HomeScreenはTeamsFeedRepositoryから最新20件を取得する。画像はプレビューせず `[画像]` と表示する。Graphの投稿者IDと保存済みトークンのユーザーIDを照合できた場合だけ自分の吹き出しを右寄せにする。ロビー・Feed・通知は同じ固定チャネルを読む。通知Host は Teams を監視し、初回取得済みの投稿は鳴らさず、新着だけBlow通知音とGoogle Cloud TTSを1回発火する。

ロビーは未認証の自動遷移を一度に制限し、認証画面から戻った後は手動の「サインイン」を待つ。通信失敗時は理由と「再試行」を表示し、再試行時はポーリングを即時再起動する。HomeActionMenuの終了行は可視領域の最下層へ配置し、共通GlassVisibleAreaは画面高さの64%を使う。

## 8. セキュリティ

- .env、.teams-token.json、アップロード共有トークン、keystoreをGit管理外とする。
- 破壊操作、返信、Teams送信APIはlocalhostまたは共有トークンを要求する。
- GraphトークンをWebブラウザへ返さない。
- 全 APK ビルドで usesCleartextTraffic=false。HTTP 例外やネットワーク設定による許可は無い。
- 正規アプリの接続先固定は、改造 APK や取得したアクセストークンの Graph 権限を縮小するものではない。

## 9. テスト

- Node: APIルート、保存、翻訳フェイク、Teams認証・送受信、Webロジック
- Android JVM: CaptureViewModel、CaptureSettings、TeamsAuth／Client、MediaSinks、Feed
- 実機: CameraX、AudioRecord、Rokid入力、TTS
