# 外部設計書

## 1. 操作

Rokid Glassesでは前後スワイプ、タップ、ダブルタップを使う。1スワイプで複数キーが発生する端末特性を考慮し、入力をデバウンスする。

| 操作 | 基本動作 |
|---|---|
| 前後スワイプ | 項目、投稿、ロビーの会話、写真の縦／横選択 |
| タップ | 決定、撮影開始、通常時はロビーの操作メニュー。認証・通信エラー時はサインイン／再試行 |
| ダブルタップ／BACK | 戻る。撮影後は下書きを保持する画面へ移動し、録音中は録音メニューを開く |

## 2. 画面

| 画面 | 内容 |
|---|---|
| ロビー | Teams会話の吹き出し、接続状態、上部の操作メニュー、サインイン／再試行 |
| 撮影 | 写真の縦／横を選び、設定済み宛先を右上に表示する |
| 送信確認 | 実際の宛先、サイズ、音声処理結果を表示して送信／取消 |
| 撮影内容の保持 | 写真とコメントを保持し、「送信確認へ」または「破棄する」を選ぶ |
| Teams認証 | デバイスコード、入力URL、進捗、戻る |
| Feed | APK に設定された単一 Teams チャネルの投稿 |
| 設定 | 返信文字サイズ、読み上げ速度、音声認識、表示・返信言語 |

## 3. 宛先固定

送受信先は APK の BuildConfig に設定された単一 Teams チャネル（開発用チャネル）だけ。設定画面の宛先切替・QR 読取・PC モニターへの HTTP 送受信は廃止する。旧保存済みの QR 接続先やモニター選択は無視し、言語・音声認識などのローカル設定は保持する。Teams 未設定時に PC へフォールバックしない。

これは正規アプリの接続先を固定するものであり、Microsoft の委任権限を単一チャネルへ限定するセキュリティ境界ではない。

## 4. 撮影

### 写真

1. 縦／横を選ぶ。安定性を優先して写真の撮影解像度は2048×1536を上限とする。
2. タップで撮影する。
3. コメントを残すか選ぶ。残す場合だけ5秒録音し、音声認識で文字起こしする。翻訳はしない。
4. Teams への送信確認を表示する。
5. 「はい」で送信する。

録音開始・録音待ち・文字起こしに失敗した場合や、無音／聞き取れない場合は写真を保持し、「録音やり直す」「コメントなしで進む」を選べる。再録音でも写真は撮り直さない。BACK・ダブルタップでは下書き保持画面へ移動する。コメントなしで進む場合も送信確認を挟み、自動送信しない。

### 動画

「動画を撮る」はロビーのメニューに準備中として表示するが、選択・撮影・送信はできない。

## 5. 送信確認

確認モーダルには「Teamsに送信しますか？」を表示する。初期選択は「いいえ」とし、意図しない外部送信を防ぐ。

「いいえ」、BACK、ダブルタップでは写真・コメントを破棄せず、保持画面へ移動する。前後スワイプで「送信確認へ」「破棄する」を選び、タップで決定する。「送信確認へ」は確認画面を開くだけで送信しない。削除は「破棄する」を明示的に選んだ場合だけ行う。下書きは撮影画面のメモリ内だけに保持し、アプリ終了時には保存されない。

送信失敗時は下書きを保持して確認画面へ戻す。Teamsの再認証が必要な場合だけ認証画面へ遷移し、完了後に撮影画面へ戻れる。

## 6. Feedと通知

Feed・ロビー・通知はすべて APK 固定の Teams チャネルを参照する。

画面表示中のみFeedを定期取得する。別画面では約10秒間隔で新着を確認し、初回取得済みの過去データは通知しない。新着時は通知音、約8秒のHUDカード、端末言語でのTTSを使用する。

ロビーはTeamsチャネルの最新会話を10秒間隔で取得する。相手と自分の投稿を簡易吹き出しで表示し、投稿者の頭文字をアイコンとして添える。Graphの投稿者IDとサインインIDを照合できた場合だけ自分の投稿を右寄せにし、判定できない場合は名前付きの中立表示にする。画像は展開せず `[画像]` と表す。Teams新着は画面上部の通知、Blow通知音、TTS読み上げで知らせる。

Rokid実機の光学的な可視範囲は画面上端から約2/3である。共通の文字・操作領域を画面高さの64%に制限し、ロビーの操作メニューを上部へ置く。メニューの「終了」は可視領域の最下層に置き、その下に表示しない。

## 7. 開発用 Preact モニター（Rokid APK からの接続は廃止）

- カード一覧で写真／動画、原文、日本語訳、端末ID、時刻を表示する。
- カードを開くと全画面表示し、日本語テキストまたはマイク音声で返信できる。
- 返信は受信元端末の設定言語へ翻訳される。
- Teamsチャット用モーダルは実装ファイルがあるが、現行画面からは開けない。

## 8. エラー表示

| 状況 | 表示・動作 |
|---|---|
| Teams未設定 | 送信先未設定として表示し、送受信しない |
| Teams未認証／期限切れ | ロビーから一度だけデバイスコード画面へ進む。戻った後はロビーの「サインイン」で再表示 |
| Teams通信失敗／Wi-Fiなし | 理由と「再試行」をロビー上部に表示。タップで即時再取得し、10秒更新も継続 |
| Graph 403 | 権限またはチャネル参加状態の確認を促す |
| Gemini解析失敗 | メディアは保存し、元コメントへフォールバック |
| 返信翻訳失敗 | 返信を登録せず、PCへ失敗表示 |
| TTS失敗 | 字幕は維持し、読み上げ失敗を表示 |
