# 開発ガイド

このブランチのAndroidアプリはSlack向けです。Slack Botの準備、PC中継サーバ、AVDへの接続は [Slackでの遠隔支援](Slackでの遠隔支援.md) を参照してください。以下のTeams設定は旧実装の参考情報です。

## 1. 必要環境

- Node.js 22.13以降
- pnpm
- Android Studio同梱JDK 21
- Android SDK
- Android実機、Rokid Glasses、またはUI確認用のAVD

## 2. 初期設定

    pnpm install --frozen-lockfile
    cp .env.example .env
    git config core.hooksPath .githooks

.envには必要な値だけを設定する。

| 値 | 用途 |
|---|---|
| MS_TENANT_ID | Entraテナント |
| MS_CLIENT_ID | パブリッククライアントアプリ |
| MS_TEAM_ID | 対象チーム |
| MS_CHANNEL_ID | 対象チャネル |
| GOOGLE_STT_TTS_TRANSLATE_API_KEY | Google STT・TTS・Cloud Translation共通 |

## 3. PCの起動

    pnpm dev

- Preact: http://localhost:5514
- Fastify: http://localhost:8787
PC API／Webは開発ツールとして残すが、Teams専用RokidアプリはPCのHTTPサーバへ接続しない。設定QRは撤去した。

## 4. Androidビルド

    export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
    export ANDROID_HOME="$HOME/Library/Android/sdk"
    bash scripts/fetch-offline-stt.sh
    ./gradlew :rokid:testDebugUnitTest
    ./gradlew :rokid:assembleDebug

APKはapp/rokid/build/outputs/apk/debug配下に生成される。

## 5. インストール

実機がない場合は `bash run.sh emu` でAVD「Rokid_Test」（480 × 640 / 240dpi）へ
UI専用ビルドを表示できる。Android Studioでの実行方法と確認範囲は[AVDでのUI確認](AVDでのUI確認.md)を参照する。

    adb devices
    adb install -r app/rokid/build/outputs/apk/debug/rokid-debug.apk

実際のAPK名は生成物に合わせる。Rokidでインストールロックが出る場合はデバイスメモを参照する。

## 6. 宛先確認

1. `.env` のMS_TENANT_ID、MS_CLIENT_ID、MS_TEAM_ID、MS_CHANNEL_IDを設定してAPKをビルドする。
2. 送受信はTeams固定。設定画面に送信先切替や設定QRはない。
3. 撮影画面右上のTeams表示を確認する。
4. 送信確認モーダルの宛先名を確認する。

Teams未設定の場合もPCへフォールバックしない。宛先の変更はビルド時設定とAPKの再ビルドで行う。
以前保存したQRのチーム・チャネル・URL・共有トークンは利用しない。端末の言語や音声認識エンジン設定は維持する。

## 7. Teams認証

1. Teams宛で送信するか、Teams Feedを開く。
2. 認証画面のコードを確認する。
3. 別端末で表示されたMicrosoft URLを開く。
4. コードを入力して許可する。
5. Rokidが元画面へ戻ることを確認する。

トークンは暗号化保存される。権限変更、管理者による失効、refresh_token失効時だけ再認証する。

実チャネルへ送信する試験は明示的な許可を得てから行う。単体テストはMockWebServerを使い、Graphへ接続しない。

## 8. 通信範囲

RokidのTeams通信はMicrosoft Graph HTTPS、認識・翻訳・読み上げはGoogle HTTPSを使用する。
PCモニターHTTP経路と接続先QRは撤去した。アプリ内のチャネル固定はMicrosoftの権限境界ではなく、
改造されたアプリに対しては専用アカウント等のMicrosoft側アクセス制御が必要。

## 9. 検証

    pnpm test:node
    pnpm check
    pnpm build
    ./gradlew :rokid:testDebugUnitTest

ログ:

    adb logcat -d | rg -i "glassreport|Teams|GoogleStt|Tts|OkHttp"

## 10. Git運用

mainへ直接pushしない。作業ブランチを作り、テスト後にPRを作成してマージする。顧客資料、.env、トークン、アップロードデータはコミットしない。
