# オフライン音声認識（Rokid）

## 構成

- sherpa-onnx **v1.13.3** Android AAR、CPU / arm64-v8a。
- SenseVoiceSmall **multilingual int8（2024-07-17）**。日・中・英・韓に対応。
- `language="auto"` で入力言語を自動判定し、原語のまま文字起こしする。表示・翻訳言語の設定から入力言語を強制しない。
- 短い録音の境界を安定させるため前後250msのゼロ波形を追加する。元の音声サンプルはすべて保持する。ITNを有効にし、日本語文字同士の不要な空白だけを除く。韓国語や英語の空白は保持する。
- モデル + tokens は **239,549,735 bytes（約228.5 MiB）**。APK内に単一モデルを同梱する。旧Whisper tiny資産がローカルに残っていてもAPKから除外する。
- 初回にアプリ専用の noBackupFilesDir へ展開するため、モデルと同じ追加ストレージも使う。旧モデルの展開済みデータは自動削除しない。
- ネットアクセス、APIキー、Google Play Services、Android標準の認識サービスは使用しない。失敗してもオンラインへ自動送信しない。

## メモリとライフサイクル

Whisper tiny/baseは日本語テストで「写真」が「真」に欠落したため、同一4音声で意味の一致したSenseVoiceを採用。ファイルサイズから推論時RAMを保証することはできない。

- 最大6秒の16kHz/mono/PCM16 WAVだけを受け付ける（通常の録音UIは5秒）。
- 推論直前にモデルをロードし、推論完了・失敗・キャンセル後に stream / recognizer を必ず解放する。常駐させない。
- プロセス共通Mutexでモデルの二重ロードを防止する。
- 600MiB未満の空きメモリ、またはOSのlowMemory状態なら開始せずエラーを返す。これは239MBモデルの展開・native作業領域を見込んだ暫定保守値であり、実RokidのピークRAM測定で調整する。この閾値でもOS強制終了を完全には防げない。
- `OfflineWavTranscriber.busy` 中はカメラを再バインドしない。JNI推論は途中中断できないため、画面キャンセル後もnative処理の終了・解放を待つ。
- 認識中にカメラを保持しないこと。撮影で既にLMKが発生している端末なので重要。
- ログには所要時間とサンプル数だけを書き、音声や認識本文を書かない。

## モデル選定比較（2026-09-30）

macOS arm64 CPU・sherpa-onnx 1.13.3・2スレッドで、Google疎通に使用した同一4つの合成音声を比較した。すべて入力言語AUTO、表示言語からの強制なし。SenseVoiceのみ前後250msの無音を追加した。

| 言語・期待文 | Whisper tiny | Whisper base | SenseVoice int8 + 境界無音 |
|---|---|---|---|
| 日: 現場の写真を確認してください。 | 現場の真を確認してください | 現場の真を確認してください | 現場 の 写真 を 確認 して ください。 |
| 中: 请检查现场的照片。 | 清查現場的照片 | 請查現場的照片 | 请检查现场的照片。 |
| 英: Please check the photos from the site. | 一致 | 一致 | 一致 |
| 韓: 현장 사진을 확인해 주세요. | 一致 | 空白の差のみ | 현장 사진 을 확인 해 주세요. |

SenseVoiceの前後無音なしでは韓国語が「확 해」に欠落した。250ms追加で「확인 해」に改善。tinyも250/500ms追加を試したが日本語の写真欠落は解消しなかった。SenseVoiceの日本語空白はアプリ側で整形する。

参考値: macCPUのロード約0.9〜1.4秒、各音声デコード約0.08〜0.16秒。これらはRokidの処理時間・ピークメモリを示す数値ではない。4文の一致は騒音下・自由発話の認識精度を保証しない。Android JNIとRokid録音の評価は別途必要。

## 実機のダミー音声検証

実際のTeams投稿やマイクを使わず、開発者が用意した4つの16kHz/mono/PCM16 WAVだけを認識する。

```bash
./gradlew :rokid:assembleDebug :rokid:assembleDebugAndroidTest \
  -PinstrumentationRunner=com.scraft.glassreport.capture.asr.OfflineSttDeviceTest
adb install -r app/rokid/build/outputs/apk/debug/rokid-debug.apk
adb install -r app/rokid/build/outputs/apk/androidTest/debug/rokid-debug-androidTest.apk
adb shell run-as com.scraft.glassreport mkdir -p files/offline-stt-test
# 開発用ダミーWAVをja.wav/en.wav/zh.wav/ko.wavとしてapp-private filesへ配置する。
adb shell am instrument -w \
  com.scraft.glassreport.test/com.scraft.glassreport.capture.asr.OfflineSttDeviceTest
```

runnerは上記4つの期待文との一致を、句読点・空白を除き大文字小文字をそろえて判定する。単なる非空を成功にはしない。
各言語のダミー認識テキスト、所要時間、解放後PSSを返す。任意の別の音声を使用する場合は期待文も更新する。
ピークRAMは別途 `dumpsys meminfo` などで観測する。インストール・実行は主担当と調整する。
製品APKは認証設定を失わないよう `install -r` で更新し、アンインストールしない。
