## 用語

| 用語 | 意味 |
|---|---|
| Teams経路 | RokidがMicrosoft Graphへ写真＋コメントを直接投稿する基本経路 |
| PCモニター経路 | Rokidが同一LANのFastify APIへ写真と任意の文字起こしコメントを送り、Preactで表示する経路 |
| 既定の送信先 | Rokid設定画面で保存する`Teams`または`モニタ`。撮影画面の右上に表示 |
| ローカル返信 | Preactから端末別キューへ入れ、Rokidが取得する返信。Teamsは経由しない |
| Feed | Teamsチャネルまたはローカル返信を表示するRokid側の投稿画面 |

## 現在の前提

- Teams設定済みなら既定の送信先はTeams、未設定ならPCモニターのみです。
- TeamsとPCモニターへ同時送信しません。確認画面に実際の宛先を表示します。
- 「動画を撮る」は準備中で選択できません。
- 撮影コメントは任意の5秒録音から文字起こしし、翻訳しません。PCからの返信の翻訳は別機能です。
- ロビーは送信先設定に関係なくTeamsチャネルを表示します。画像は `[画像]` と表示します。
- Teams APIは受送信とも実装済みです。PreactのTeamsモーダルはUI未接続です。
- PC経路は同一LAN、Teams経路はインターネット接続を必要とします。
