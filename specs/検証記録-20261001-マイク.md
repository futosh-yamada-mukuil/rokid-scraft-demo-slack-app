# Rokidマイク無音化表示の修正

## 実測と原因

2026-10-01、接続中のRG_glassesでコメント録音が約0.5秒で中断した。
マイク権限は許可済み、グローバルミュートとセンサープライバシーはOFF、ActivityはTOPだった。

同一のMIC / 16kHz / mono / PCM16で6秒間読み取りを継続したところ、
`AudioRecord.activeRecordingConfiguration.isClientSilenced` はずっとtrueだったが、
PCM最大振幅1341、非ゼロサンプル69119を取得できた。
つまり、この端末ではフラグだけから実際のPCMが無音かを判定できない。

## 修正

`mukuil-one` の `MicCaptureThread` と同じ入力源・フォーマット・継続読み取りを使い、
フラグによる即時例外を削除した。無音判定は既存の実PCM最大振幅に基づく。
権限、プライバシー設定、入力源は変更しない。

## 確認結果

- Androidユニットテスト、デバッグAPKビルド成功。
- 修正版を実機へ上書きインストール。
- 本番 `VoiceRecorder.record(5000)` が例外なく完了。5000ms、WAV 160044 bytes。
- 本番録音試験のpeakは246で、正常に「無音」と分類された。発話内容のSTT成功とは別の確認である。
- 音声は保存・送信していない。Teams投稿も行っていない。

## 手動再検証

`MicrophoneDeviceTest` を明示的な計測時だけ選んでビルドする。
通常の自動テストでは実マイクを開かない。

```sh
./gradlew :rokid:assembleDebugAndroidTest -PinstrumentationRunner=com.scraft.glassreport.capture.asr.MicrophoneDeviceTest
adb install -r app/rokid/build/outputs/apk/androidTest/debug/rokid-debug-androidTest.apk
# フラグとPCM振幅を6秒測定（音声を保存・送信しない）
adb shell am instrument -w com.scraft.glassreport.test/com.scraft.glassreport.capture.asr.MicrophoneDeviceTest
# 本番の5秒録音とWAV長を検証（音声を保存・送信しない）
adb shell am instrument -w -e production true com.scraft.glassreport.test/com.scraft.glassreport.capture.asr.MicrophoneDeviceTest
```

実際の発話の文字起こしは、写真撮影→コメント録音で確認する。送信確認ではTeamsへ送らない。
