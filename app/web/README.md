# app/web — PC受信モニター

Vite／Preact製の開発用受信モニターです。PC APIへテスト送信した写真・動画、原文、日本語訳をリアルタイム表示します。配布用RokidアプリはTeams専用で、このHTTPモニターへの送信・返信取得は行いません。

## 起動

```bash
pnpm dev
```

- Web: `http://localhost:5514`
- API: `http://localhost:8787`

同一LANの別端末からもWebの一覧を開けます。認証が必要な開発用返信・Teams操作は、localhost限定のトークン取得APIを使うためPC本体のブラウザから実行してください。

## 機能

- 写真・動画の一覧、全画面表示、拡大、動画再生
- 原文とPC向け日本語訳の表示
- SSEによる新着・削除同期
- 個別削除、全削除、テーマ切替
- 日本語テキストによる端末返信
- PCマイク音声のAUTO認識と端末言語への翻訳

開発用返信はTeamsを経由せず、受信データの端末IDに対応するローカルキューへ入ります。配布用Rokidアプリはこのキューを取得しません。PC内での疎通テスト用として維持しています。

## Teams機能の位置づけ

Teamsチャネルの取得・テキスト送信・Device Code Flow用のAPIクライアントと`TeamsChatModal`はコード上にありますが、現在のモニター画面にはモーダルを開く導線を接続していません。通常のTeams運用ではRokidがMicrosoft Graphへ直接投稿し、PCではTeamsクライアントを使用します。

## Rokid設定QRの廃止

設定QRの生成画面・入口・符号化処理は削除しました。旧URL `#/config` を開いてもモニターが表示されます。WebからRokidのHTTP宛先やTeamsチーム／チャネルを変更する機能はありません。旧QR設定のブラウザ保存値もAPI操作には使用しません。
